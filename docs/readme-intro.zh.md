## 关于 Kling 4.0 系列

本合集围绕 Kling 4.0 系列整理视频提示词。模型信息依据作者原帖，原始版本标注保留在来源备注中。

案例涵盖动作编排、角色动画、喜剧和旅行短片，保留完整原文及作者来源；需要参考素材的案例另附输入参考图。模型信息见 [Kling AI 官方网站](https://kling.ai/)。
