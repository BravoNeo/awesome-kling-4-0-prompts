## 关于 Kling 4.0 Flash

Kling 4.0 Flash 是本合集创作者使用并注明的视频模型。这些案例展示了如何在连续镜头中描述动作、运镜、对白和声音。最新模型信息与创作工具见 [Kling AI](https://kling.ai/)。

## 如何使用

1. 先看视频，展开完整原文，了解镜头、动作和声音怎样配合。
2. 根据案例准备角色或场景参考图，并选择合适的画幅与时长。
3. 将提示词复制到支持该模型的工具，按自己的故事改写，再逐步调整。中文编辑稿另列在原文下方。
