## 如何使用这些案例

1. 点击预览观看视频，观察动作、节奏和镜头。
2. 阅读输入说明；如果提供参考素材，先准备对应角色或场景图。
3. 展开「完整原始提示词」，复制到支持所标注模型的工具中，再按自己的故事调整。中文编辑稿与原文分开保留。

在使用的工具中选择准确模型和可用参数。作者提示词描述创作意图，不代表效果保证或官方规格。模型信息见 [Kling AI](https://kling.ai/)。
